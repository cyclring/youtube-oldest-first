# YouTube 오래된 순 정주행

YouTube 채널 영상을 가장 오래된 것부터 순서대로 이어서 재생하는 Tampermonkey 유저스크립트입니다.

## 설치

1. 크롬에 Tampermonkey 확장 프로그램을 설치하고, 확장 프로그램 관리에서 "사용자 스크립트 허용"(또는 "개발자 모드")을 켭니다.
2. 아래 주소를 크롬에서 엽니다. Tampermonkey 설치 화면이 뜨면 **설치**를 누릅니다.

   https://raw.githubusercontent.com/cyclring/youtube-oldest-first/main/youtube-oldest-first.user.js

새 버전이 올라오면 Tampermonkey가 자동으로 받아 옵니다. 바로 받으려면 Tampermonkey 메뉴의 "유저 스크립트 업데이트 확인"을 누르세요.

## 사용법

- 채널 페이지 오른쪽 아래의 **▶ 오래된 순 정주행** 버튼을 누르면 가장 오래된 영상부터 재생합니다. Shorts는 뺍니다.
- 영상이 끝나면 다음 영상으로 자동으로 넘어갑니다.
- 재생 중 패널의 **목록**을 누르면 전체 순서가 보이고, 원하는 영상을 눌러 바로 이동할 수 있습니다.
- 어디까지 봤는지 채널별로 기억합니다. 다시 채널에 가면 **이어보기**가 나옵니다.

PC 브라우저(www.youtube.com) 전용입니다. 휴대폰 YouTube 앱에서는 동작하지 않습니다.
