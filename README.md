# YouTube 오래된 순 정주행

YouTube 채널 영상을 가장 오래된 것부터 순서대로 이어서 재생하는 Tampermonkey 유저스크립트입니다.

## 설치

1. 크롬에 Tampermonkey 확장 프로그램을 설치하고, 확장 프로그램 관리에서 "사용자 스크립트 허용"(또는 "개발자 모드")을 켭니다.
2. 아래 주소를 크롬에서 엽니다. Tampermonkey 설치 화면이 뜨면 **설치**를 누릅니다.

   https://raw.githubusercontent.com/cyclring/youtube-oldest-first/main/youtube-oldest-first.user.js

새 버전이 올라오면 Tampermonkey가 자동으로 받아 옵니다. 바로 받으려면 Tampermonkey 메뉴의 "유저 스크립트 업데이트 확인"을 누르세요.

## 사용법

- 버튼과 패널은 화면 오른쪽 위에 있고, 몇 초 뒤 자동으로 숨어 오른쪽 끝에 얇은 손잡이만 남습니다. 손잡이에 마우스를 올리면 다시 펼쳐집니다.
- 채널 페이지에서 **▶ 오래된 순 정주행** 버튼을 누르면 가장 오래된 영상부터 재생합니다. Shorts는 뺍니다.
- 채널이 만든 재생목록은 채널 페이지 패널의 **재생목록** 버튼을 누르면 목록이 나오고, 재생목록마다 **정주행**(재생목록 순서)과 **거꾸로**를 고를 수 있습니다. 재생목록 페이지나 재생목록으로 재생 중인 화면(`list=`가 붙은 주소)에서도 **▶ 재생목록 정주행** / **⇅ 거꾸로 정주행** 버튼이 나옵니다. 최신 편이 맨 위에 있는 재생목록은 "거꾸로"를 고르면 1화부터 봅니다. 비공개 재생목록, 나중에 볼 동영상, 좋아요 목록은 지원하지 않습니다.
- 영상이 끝나면 다음 영상으로 자동으로 넘어갑니다.
- 재생 중 패널의 **목록**을 누르면 전체 순서가 보이고, 원하는 영상을 눌러 바로 이동할 수 있습니다.
- 목록 위의 **재생목록으로 저장**을 누르면 지금 순서 그대로 내 YouTube 계정에 **비공개 재생목록**으로 저장합니다. YouTube에 로그인돼 있어야 하고, 저장한 뒤에는 휴대폰 YouTube 앱에서도 그 순서로 볼 수 있습니다. 저장 이후에 올라온 새 영상은 자동으로 추가되지 않습니다.
- 어디까지 봤는지 채널·재생목록별로 기억합니다. 다시 채널에 가면 **이어보기**가 나옵니다.

PC 브라우저(www.youtube.com) 전용입니다. 휴대폰 YouTube 앱에서는 동작하지 않습니다.
